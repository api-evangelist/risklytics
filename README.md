# Risklytics

## Removed from the catalog

**This profile has been removed at the company's request (2026-11-18), and the request was honored.**

API Evangelist previously maintained an independent, third-party profile of this company's publicly
available API surface. That profile has been withdrawn. The `apis.yml` descriptor, every derived
artifact, every API and specification page, and the company's rating have all been deleted, and this
repository's history has been reduced to this notice.

### What remains

A minimal record is still published on [APIs.io](https://apis.io/providers/risklytics/) so the company is not silently erased from
a public index it was listed in. It carries only these facts:

- **Name:** Risklytics
- **Description:** Risklytics is a commercial insurance brokerage based in San Francisco.
- **Website:** https://www.risklytics.com/
- **Rating:** **unrated** — no Kin Score, no Agent Readiness score

**Unrated is not a zero.** A company that asks to be removed is never scored zero for having asked.
There is no rating here because we no longer index this company's API surface, not because anything
about it was found wanting.

The company is recorded on the API Evangelist delisting registry, which every harvesting, enrichment
and scoring pipeline in the network consults before it runs. It will not be re-profiled from public
sources.

### Removal requests

Removal is free, requires no partnership or purchase, and needs no justification. If you represent a
company profiled by API Evangelist and want the listing taken down — in full, or reduced to a record
like this one — email [info@apievangelist.com](mailto:info@apievangelist.com). Acknowledgement within
one business day, removal or restriction within two.
